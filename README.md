# Unitl-Dawn  
**UNTIL DAWN**

---

## Descrizione del gioco

**UNTIL DAWN** è un videogioco **2D Wave Survival** in cui il giocatore deve sopravvivere a ondate successive di nemici, con una difficoltà che aumenta progressivamente.  
L'obiettivo principale è resistere dieci notti di incessanti orde di mostri, utilizzando abilità, strategia e riflessi.

Il gioco mette alla prova la capacità del giocatore di adattarsi a nemici sempre più numerosi e pericolosi, offrendo un'esperienza dinamica e impegnativa.

## Tecnologie utilizzate

- **Linguaggio di programmazione:** Java

Il progetto è stato realizzato interamente in Java, sfruttando `JPanel` per la gestione della grafica, del rendering degli oggetti di gioco e delle interazioni.

## Obiettivo del gioco
